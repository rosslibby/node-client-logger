# @notross/node-client-logger
A logging utilitiy featuring in-memory history, optional console output, user-supplied callback support, and filtering by level.

### LogLevel enum
```typescript
enum LogLevel {
  'debug' = 'debug',
  'error' = 'error',
  'info' = 'info',
  'log' = 'log',
  'warn' = 'warn',
}
```
